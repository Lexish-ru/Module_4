# Проект: Поиск и управление вакансиями

## Описание
Этот проект позволяет искать вакансии на HeadHunter, сохранять их в JSON-файл, фильтровать, сортировать и управлять сохраненными вакансиями через консольный интерфейс.

## Функциональность
- Получение вакансий с HH.ru по ключевому слову.
- Сохранение вакансий в JSON-файл.
- Отображение сохраненных вакансий.
- Фильтрация вакансий по минимальной зарплате.
- Сортировка вакансий по зарплате.
- Удаление вакансии.
- Очистка хранилища вакансий.

## Установка и запуск
### Требования
- Python 3.12+
- `pip` или `poetry` для управления зависимостями

### Установка зависимостей
#### Через pip:
```sh
pip install -r requirements.txt
```

#### Через poetry:
```sh
poetry install
```

### Запуск
```sh
python main.py
```
